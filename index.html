01 — การสร้างรูปด้วย AI

AI Image Generation

ทดสอบว่าความเจาะจงของ prompt ส่งผลต่ออารมณ์ของภาพสินค้ามากแค่ไหน จากคำสั่งกว้างๆ ไปจนถึงคำสั่งระดับกำกับแสงและองค์ประกอบภาพ

Zero-shot prompt

"A picture of modern wireless earbuds."

ได้ภาพหูฟังสีขาว/ดำ 3 แบบ ตรงตามคำในคำสั่ง แต่พื้นหลังเรียบธรรมดาแบบภาพสต็อกทั่วไป

Context prompt

"Commercial product screenshot of sleek matte-black wireless earbuds sitting inside an open minimalist charging case, floating in mid-air, neon blue and violet atmospheric backlighting, shallow depth of field, 8k resolution, highly detailed product photography."

ได้ภาพหูฟังสีดำด้าน ลอยเหนือกล่องเคส แสงนีออนฟ้า-ม่วง มีมิติความชัดลึก ดูเหมือนภาพโฆษณามืออาชีพ

สะท้อนการเรียนรู้ — zero-shot ให้ภาพตรงตามคำศัพท์แต่ไม่อบอุ่นพอ ส่วน context prompt ที่ระบุแสง มุมกล้อง และความรู้สึกของภาพ ทำให้ AI เข้าใจ "โทน" ที่ต้องการได้อย่างชัดเจน

02 — การอธิบายความสัมพันธ์ทางคณิตศาสตร์

Desmos Calculator — ANC Wave Visualizer

จำลองหลักการ Active Noise Cancellation (ANC) ด้วยสมการฟิสิกส์คลื่นเสียงรบกวนภายนอกและคลื่นต้านที่ถูกกลับเฟส

N(x) — เสียงรบกวนภายนอก Aₙ(x) — คลื่นต้านกลับเฟส R(x) — เสียงคงเหลือที่ผู้ใช้ได้ยิน
100%
Noise Reduction (φ → 0 คือหักล้างสมบูรณ์)
● Zero-shot prompt

"ขอสมการกราฟคลื่นเสียง attenuation สำหรับหูฟังตัดเสียงรบกวน"

ให้สมการ y = \sin(x) หรือ y = e^{-x} แบบโดดๆ ซึ่งไม่ได้แสดงการหักลบของคลื่นเสียง(Destructive Interference) หรือความถี่ของเสียงรบกวนอย่างชัดเจน

● Context prompt

"ช่วยสร้างชุดสมการสำหรับ Desmos เพื่ออธิบายระบบ Active Noise Cancellation (ANC) ของ Wireless Earbuds โดยมี: 1. คลื่นเสียงรบกวนภายนอก N(x) = A * sin(w * x) 2. คลื่นต้าน phase-inverted A(x) = -A * sin(w * x - phi) โดยใช้ตัวแปร phi เป็น Slider 3. คลื่นผลลัพธ์ R(x) = N(x) + A(x) ขอรูปแบบโค้ดสมการที่สามารถ Copy-Paste ลง Desmos ได้ทันที"

ได้คำอธิบายที่เห็นภาพชัดเจน มีการเปรียบเปรย และเจาะจงกลุ่มเป้าหมาย

สะท้อนการเรียนรู้ — คำสั่งที่ระบุตัวแปรและความหมายเชิงฟิสิกส์ (Phase shift / Latency) ช่วยให้ได้ชุดสมการที่ผูกกับ slider และจำลองการหักล้างของคลื่นเสียง (destructive interference) ได้จริง

03 — การสร้าง Diagrams จาก Mermaid Code

Mermaid.ai Sequence Diagram

แสดงผังการทำงานของสถาปัตยกรรมบลูทูธ และการประมวลผลสัญญาณดิจิทัล (DSP) ภายในหูฟังไร้สาย

● Zero-shot prompt

"เขียน Mermaid code แสดงการทำงานของ Wireless Earbuds"

ได้ไดอะแกรมแบบง่าย เช่น [Phone] -> [Earbuds] -> [Speaker] ซึ่งขาดรายละเอียดเชิงเทคนิคและสถาปัตยกรรมบลูทูธ

● Context prompt

"อยากให้เพิ่ม Mermaid Code ประเภท sequenceDiagram แสดงกระบวนการทำงานของ Wireless Earbuds ดังนี้: 1. การเชื่อมต่อ Bluetooth (Pairing/Handshake) ระหว่าง Smartphone และ Earbuds (Primary/Secondary) 2. การส่งสัญญาณ A2DP Audio Stream 3. การประมวลผลภายในหูฟัง: รับสัญญาณ ผ่าน DSP Engine เปิดระบบ ANC ส่งไปยัง Speaker Driver ขอเป็นบล็อกโค้ด mermaid เท่านั้น "

การระบุโครงสร้าง Sequence Diagram และระบุ Actor/Participant แต่ละฝ่าย ช่วยให้ได้โค้ด Mermaid ที่แสดงวิศวกรรมระบบ (Systems Architecture) ได้อย่างเป็นมืออาชีพ

สะท้อนการเรียนรู้ — การระบุประเภทแผนภาพ (sequenceDiagram) พร้อมชื่อ actor/participant แต่ละฝ่าย ช่วยให้ AI สร้างโค้ด Mermaid ที่สื่อสารสถาปัตยกรรมระบบได้ละเอียดกว่าแผนผังทั่วไปมาก

04 — การสร้างบทความจาก LaTeX

LaTeX · Overleaf IEEE Paper

สร้างบทความวิชาการรูปแบบ IEEE พร้อมตารางเปรียบเทียบ Audio Codec แบบ booktabs ที่พร้อมสำหรับการ compile

Zero-shot prompt

"เขียนบทความเกี่ยวกับเทคโนโลยี Wireless Earbuds เป็น LaTeX ภาษาอังกฤษ ใส่ชื่อ Hironobu Chaikasem"

Evolution, Architecture, and Future Horizons of TWS Audio Systems
Hironobu Chaikasem
Wireless earbuds, commonly referred to as True Wireless Stereo (TWS) devices, have transitioned from niche acoustic novelties to ubiquitous personal computing platforms...

ได้ไฟล์ .tex ที่เป็นบทความไหลต่อเนื่อง ไม่มีโครงสร้างตาราง การอ้างอิง หรือส่วนประกอบวิชาการสมบูรณ์

Context prompt (IEEE Format)

"อยากให้ทำในรูปแบบบทความวิชาการ (IEEE Format) หัวข้อ "Evolution and Technical Architecture of Modern Wireless Earbuds" โดยมีเงื่อนไขดังนี้: 1. ใช้ documentclass{article} พร้อม package hyperref, booktabs, graphicx 2. มี Abstract, Keywords, Section: Introduction, Core Technologies (Bluetooth Codecs, ANC, Battery Management) 3. มี ตารางเปรียบเทียบ Codecs (SBC vs AAC vs LDAC) โดยใช้ booktabs 4. ให้โค้ดพร้อมคอมไพล์บน Overleaf ได้ทันทีโดยไม่ติด Error 5.ใส่ชื่อ Mr.Hironobu Chaikasem Computer Engineering and Artificial Intelligenceลงไปด้วย"

สะท้อนการเรียนรู้ — การระบุ format (IEEE), package ที่ต้องใช้, และโครงสร้างตารางที่ต้องการ ทำให้ได้เอกสารวิชาการที่ครบองค์ประกอบและคอมไพล์ได้จริงโดยไม่ error

05 — การสร้าง Slide สรุปงานด้วย NotebookLM

NotebookLM Executive Slide Blueprint

สรุปข้อมูลงานวิจัยให้กลายเป็นสไลด์นำเสนอผู้บริหารที่กระชับและตรงประเด็น

● Zero-shot prompt

"สรุปเอกสารนี้เพื่อเอาไปทำสไลด์ให้หน่อย"

ได้สรุปแบบข้อความยาวๆ ไม่แบ่งหน้าสไลด์ให้ชัดเจน ข้อมูลอาจขาดความต่อเนื่องเวลาจัดหน้าจริง

● Context prompt

"อ้างอิงจากข้อมูลใน Notebook นี้ ช่วยออกแบบเค้าโครง Presentation สำหรับนำเสนอผู้บริหาร ในหัวข้อ "Wireless Earbuds Market & Tech Trends" โดยรูปแบบการตอบในแต่ละสไลด์ให้แบ่งดังนี้: Slide Title Main Visual / Graphic Concept (คำแนะนำภาพที่ควรใช้) Key Bullet Points (ไม่เกิน 3 ข้อ ข้อละ 1 บรรทัด) "

ได้โครงสร้างที่แบ่งเป็นหน้าชัดเจน ดึงประเด็นสำคัญมาเป็น Bullet points พร้อมนำไปวางในสไลด์ได้ทันที

สะท้อนการเรียนรู้ — การระบุ format (IEEE), package ที่ต้องใช้, และโครงสร้างตารางที่ต้องการ ทำให้ได้เอกสารวิชาการที่ครบองค์ประกอบและคอมไพล์ได้จริงโดยไม่ error
