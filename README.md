# Wireless Earbuds — AI Workflow Showcase

## อัปโหลดและเปิดเว็บไซต์

1. แตกไฟล์ ZIP นี้ก่อน
2. สร้าง repository ใน GitHub แล้วเลือก Add file → Upload files
3. อัปโหลดไฟล์ทั้งหมดภายในโฟลเดอร์นี้ โดยให้ index.html อยู่ที่หน้าหลักของ repository
4. กด Commit changes
5. ไปที่ Settings → Pages เลือก Deploy from a branch แล้วเลือก main และ / (root) จากนั้น Save
6. รอ GitHub Pages เผยแพร่ แล้วเปิดลิงก์เว็บไซต์ที่แสดงในหน้า Pages

ไม่ต้องติดตั้งแพ็กเกจหรือสั่ง build
เก็บชื่อไฟล์เดิมไว้ เพราะหน้าเว็บอ้างอิงชื่อรูปและเอกสารเหล่านี้
PDF เป็นสำเนาลดขนาดสำหรับเว็บ ส่วนต้นฉบับยังอยู่ในโฟลเดอร์งานเดิม
ฟอนต์และ Google Slides ใช้อินเทอร์เน็ตในการโหลด
